# Contributing

Thank you for helping improve the articles on [cfd.university](https://cfd.university/). Corrections, clarifications and additions are all welcome, from a single typo to a rewritten section.

There are two ways to contribute:

- **Open an issue**: describe what is wrong or unclear. This is the right route if you are not comfortable editing raw HTML, or if the change affects code listings (see the note on code snippets below). 
- **Submit a pull request**: edit the raw HTML directly and propose the change. Every article page on the website has an *Edit on GitHub* and an *Open issue on GitHub* button that will bring you to the right file.

Once a pull request is reviewed and merged, the change propagates automatically to the website on the next sync.
